\tbkSection{\str{sec.main_menu}}

\tbkSubsection{\str{sub.internet}}

\textbf{Ethernet Connection:}

Connect the Asclepius to the Ethernet interface (10/100/1000 Base-T) using a
standard network cable.

\textbf{WiFi Connection:}

\begin{tbkSteps}
  \item Click the WiFi icon \tbkIcon{wifi} on the main menu screen.
  \item Select a WiFi name you want to connect. If the name of the WiFi
        you want to connect does not appear automatically, click the
        refresh button \tbkIcon{refresh} until it appears.
  \item After clicking the keyboard icon, touch the password input field
        to enter the WiFi password.
  \item After entering the password, click the Connect icon.
  \item After the connection is completed, click refresh again until the
        WiFi name selected by the user appears in the current network field.
\end{tbkSteps}

\tbkCaution{\str{call.caution_wifi}}

\tbkSubsection{\str{sub.language}}

Change the language of the software through the settings menu. Multiple languages
are supported for international users.

\tbkSubsection{\str{sub.screen}}

\tbkSubsubsection{\str{subsub.screen_sync}}

\begin{tbkSteps}
  \item Connect the HDMI cable to the HDMI port of the multi-touch digital
        image dissection table.
  \item Press the screen synchronization button on the main screen to
        synchronize the screen to the external monitor.
  \item If the sharing screen is a touch screen, plug one end of the USB
        cable into the USB socket of the dissection table, and the other
        end into the USB socket of the sharing screen.
\end{tbkSteps}

\tbkSubsubsection{\str{subsub.screen_flip_vh}}

The screen can be flipped vertically or horizontally to match the table orientation.

\tbkSubsubsection{\str{subsub.screen_flip_h}}

Horizontal screen flip is convenient for teachers to teach in various positions
around the table.

\tbkSubsection{\str{sub.online_update}}

If the Asclepius table is connected to the internet, every time the dissection
table is started, it will automatically detect whether there is a newer version
available.

\tbkWarning{\str{call.warning_update}}

\tbkSubsection{\str{sub.tech_support}}

If troubleshooting steps cannot resolve your issue, please contact us.
We will use the remote support function to provide online assistance.

\tbkSubsection{\str{sub.equipment_info}}

Press the information button \tbkIcon{info} to display detailed information about
the device, including model number, software version, and system specifications.

\tbkTip{\str{call.tip_password}}

\tbkSubsection{\str{sub.shutdown}}

\begin{tbkSteps}
  \item Press the shutdown button on the main interface of the software.
  \item Confirm to turn off.
  \item Wait for the screen of the multi-touch digital image dissection table
        to be completely dark.
  \item Wait until the sound of the main unit has stopped.
  \item Switch the power switch to 0.
  \item Put the dust cover back on the screen to protect it from getting dirty.
\end{tbkSteps}
