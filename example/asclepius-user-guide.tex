\tbkChapter{Setup And Start}

\tbkDanger{
  Please carefully read all the installation instructions before use of the
  multi-touch digital image dissection table for the first time.
}

This product includes instructions for the hardware computer equipment and software
program system. Please read this manual carefully before using this product and follow
the system start-up mode to enable and operate the multi-touch digital image dissection
table properly to avoid personnel injury and other damages caused by improper usage.

\tbkInfo{
  If you have any questions, please refer to the instruction documentation of the
  multi-touch digital image dissection table. If further instruction or clarification
  is needed, please contact us.
}

\tbkSection{Start}

Configure the hardware equipment and power cord to start operation of the
multi-touch digital image dissection table.

\begin{tbkSteps}[prefix=Step]
  \item Connect the console of the Asclepius to the AC power cord.
        Plugs may vary based on your country.
  \item Turn on the Asclepius. At this time you will hear the sound
        of the host running.
  \item Wait for the system to initialize and display the main menu.
\end{tbkSteps}

\tbkNotice{
  Please ensure the power supply matches local voltage standards before connecting.
}

\tbkSection{Main Menu Setting}

%% ............................................................................
\tbkSubsection{Connecting the Internet (WI-FI or Ethernet)}

\textbf{Ethernet Connection:}

Connect the Asclepius to the Ethernet interface (10/100/1000 Base-T) using a
standard network cable.

\textbf{WiFi Connection:}

\begin{tbkSteps}
  \item Click the WiFi icon \tbkIcon{wifi} on the main menu screen.
  \item Select a WiFi name you want to connect. If the name of the WiFi
        you want to connect does not appear automatically, click the
        refresh button \tbkIcon{refresh} until it appears.
  \item After clicking the keyboard icon, touch the password input field
        to enter the WiFi password.
  \item After entering the password, click the Connect icon.
  \item After the connection is completed, click refresh again until the
        WiFi name selected by the user appears in the current network field.
\end{tbkSteps}

\tbkCaution{
  WiFi name must be composed of English letters. Chinese names will not be displayed.
}

The Asclepius is equipped with an electronically controllable platform which
enables converting the table position from Horizontal to Vertical using the remote.

\tbkInfo{
  Taking into consideration safety, the table also comes with surge protection.
  In case the power is cut off during movement from horizontal to vertical,
  the table stays at its own place and neither goes up nor down.
}

To move the multi-touch digital imaging anatomy table:

\begin{tbkSteps}
  \item Release the movable caster brake pedal on the base.
  \item Ensure smooth movement of the table.
  \item Lock the casters again when in position.
\end{tbkSteps}

\tbkSection{Lifting Control}

\tbkDanger{
  When the warning sound ``beep'' is heard, please stay away from the multi-touch
  digital image dissection table. Wait until the process is complete before approaching.
}

\textbf{Operating Instructions:}

\begin{tbkList}
  \item Long press the \textbf{Tilt Upward} button to raise the table to vertical position
  \item Long press the \textbf{Tilt Downward} button to lower the table to horizontal position
\end{tbkList}

\tbkWarning{
  Do not continuously perform the hardware rotation. Each time the operation to
  switch the upright/flat function must wait for at least \textbf{5 minutes}
  before performing the hardware rotation again.
}

\begin{tbkCallout}[type=notice, title=Safety Protection Mechanism]
  Due to the safety mechanism, if the machine is operated continuously for more
  than 3 times in a short period of time (within 5 minutes), the dissection table
  will enter the ``safety protection mechanism'' and be locked for \textbf{18 minutes}.

  During this period, the vertical or horizontal function cannot be executed.
  Please wait patiently. After the mechanism is unlocked, the machine can resume
  rotating to the vertical or horizontal function.
\end{tbkCallout}

\tbkCaution{
  The lifting mechanism is a shared system. When there is more than one multi-touch
  digital image dissection table in the same space, operating the lifting mechanism
  may cause all tables to perform the lifting mechanism simultaneously.
}

To prevent synchronous action:
\begin{tbkList}
  \item Remove the emergency stop latch of the lifting system of other tables
  \item Or disconnect other tables from power
\end{tbkList}

\textbf{Emergency Stop:}

If you need to stop the vertical/horizontal function in an emergency, pull the
emergency stop latch on the lower left door panel immediately.

\tbkNotice{
  After the emergency stop latch is pulled out, reinsert it after the emergency
  is removed. The upright/lying down function operation will then resume.
}

\tbkDanger{
  \textbf{Do not carry the multi-touch digital imaging dissection table during
  the switch between upright and flat functions to avoid danger.}

  \textbf{For Safety Reason: Do not leave the table in inclined position.}
}

\tbkSection{Precautions}

\tbkWarning{
  System damage caused by not following these precautions, abnormal behavior,
  or human factors will \textbf{not} be covered under warranty.
}

\tbkSubsection{Precautions For Power Plug And Power Cord}

\begin{tbkWarningList}
  \item Please fully insert the power plug into the power socket (if the plug
        is loose, it may cause the table to fail to operate).
  \item Do not damage the power cord (This may result in fire, electric shock, etc.).
  \item Do not touch the power plug and power cord when your hands are wet.
\end{tbkWarningList}

\tbkSubsection{Precautions For Transport And Installation}

\begin{tbkWarningList}
  \item When transporting and installing, ensure the screen is completely flat.
        Be careful with the screen.
  \item Do not move cart with display in highest position.
  \item Do not push cart from front or back of lift.
  \item Have the panel at the lowest position while moving the trolley.
  \item Do not squeeze the outer box and product during transport.
  \item Pay attention to the operating environment. Uneven ground may cause
        the table to fall and be damaged.
  \item Do not disassemble, modify, or change the dissection table.
  \item Keep the installation site ventilated. Do not block the vents.
  \item Maintain a safe distance before using the lift/tilt mechanism.
  \item Duty cycle: rest for 18 minutes for every 2 minutes continuous
        operation of lift/tilt mechanism.
  \item For Safety Reason: Do not leave the table in inclined position.
\end{tbkWarningList}

\tbkSubsection{Precautions For Information Safety}

\begin{tbkWarningList}
  \item When operating, ensure the power cord is connected. Improper power-off
        may cause damage to the host computer and software data.
  \item Use the lock at all times to avoid slipping/sliding of the equipment.
  \item Improper storage or use will void the manufacturer warranty.
  \item Be careful of the legs of the equipment stands. Do not trample on them.
  \item The platform should not be used to store any materials (books, drinks, etc.)
        as the surface is not waterproof.
  \item Use appropriate force when clicking. Do not press or tap the screen heavily.
  \item Do not use pens, pencils, rulers, or any sharp objects to operate the screen.
  \item Age 10 or less are not advised to use the equipment without parental consent
        and supervision by authorized personnel.
  \item Do not deliberately dismantle the touch screen, system body, or workstation.
\end{tbkWarningList}

\tbkSubsection{Cleaning Consideration}

\begin{tbkCallout}[type=caution]
  Please do not use volatile materials, commercially available cleaners, or water
  to rinse and clean. This may cause damage to the screen glass, panel, or hardware
  circuit board.

  Please use the special wiping cloth for the screen to dry wipe.

  When not in use, please cover the table with the special dust jacket provided.
\end{tbkCallout}

\tbkSection{Troubleshooting}

\tbkSubsection{Unable To Boot Normally}

\begin{tbkSteps}
  \item Confirm whether the host computer and touch screen power supply are
        normally connected and powered on.
  \item Confirm whether the power transformer is normally turned on.
  \item If power is connected, confirm whether the host computer is powered on.
        Otherwise, press the power on key.
  \item If still cannot power on normally, contact technical support (Section 2-5).
\end{tbkSteps}

\tbkSubsection{Unable To Operate Normally}

If the software operation is completely inoperable and the software cannot be
switched during use:

\textbf{Keyboard Hot Keys:}

\begin{tbkTable}[caption={Emergency Keyboard Shortcuts}]
  \tbkRow{\tbkShortcut{Ctrl+Alt+F1}}{Shut down}
  \tbkRow{\tbkShortcut{Ctrl+Alt+F2}}{Restart}
  \tbkRow{\tbkShortcut{Ctrl+Alt+F11}}{Close and restart the software}
\end{tbkTable}

If hot keys cannot work:
\begin{tbkSteps}
  \item Press the host computer power switch for \textbf{five seconds} to shut down.
  \item Restart the system.
  \item If the system still fails to operate normally, contact technical support.
\end{tbkSteps}
