\tbkChapter{Introduction}

Welcome to the \textbf{TbK Library Showcase}. This document demonstrates all the features available in the TbK (Technical Book) LaTeX library for creating professional technical documentation.

\tbkSection{What is TbK?}

TbK is a comprehensive LaTeX library designed for creating professional technical documentation. It provides:

\begin{tbkList}
  \item Consistent styling across all document elements
  \item Professional table and figure handling
  \item Callout boxes for warnings, notes, and tips
  \item Specification tables for technical data
  \item Customizable headers and footers
  \item Cover page generation
\end{tbkList}

\tbkSection{Document Structure}

This showcase is organized into the following sections:

\begin{tbkNumberedList}
  \item \textbf{Typography} -- Text styling and formatting
  \item \textbf{Lists} -- Various list types
  \item \textbf{Tables} -- Data presentation
  \item \textbf{Callouts} -- Informational boxes
  \item \textbf{Icons} -- Visual elements
\end{tbkNumberedList}

\tbkChapter{Typography}

\tbkSection{Text Emphasis}

TbK uses a professional sans-serif font family by default. You can use standard LaTeX commands for emphasis:

\begin{itemize}
  \item \textbf{Bold text} for important terms
  \item \textit{Italic text} for emphasis
  \item \texttt{Monospace text} for code and technical terms
  \item \underline{Underlined text} when needed
\end{itemize}
